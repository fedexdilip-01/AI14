📌 What & Why Build a Small NN?

✦ What is a small neural network?

A compact feedforward network (Multi-Layer Perceptron) with 1-3 hidden layers. Used for classification, regression, or as a learning prototype before scaling up.

🎯 Why build from scratch (with frameworks)? — Understand core concepts (forward pass, backprop, optimization). Frameworks like TF/PyTorch abstract low-level ops but let you design architectures flexibly.
💡 Example task: Classify handwritten digits (MNIST) using a 2-layer neural network. Input: 784 pixels → Hidden: 128 neurons (ReLU) → Output: 10 classes (Softmax).

📌 Where used: Rapid prototyping, learning deep learning basics, building custom models for small-scale research, edge AI, and teaching.

⚙️ How: Core Components

🧩 Essential pieces
  • Layers (Dense/Linear, Activation)
  • Loss function (CrossEntropy, MSE)
  • Optimizer (Adam, SGD)
  • Training loop (forward pass, backward, update)
✅ Both TensorFlow and PyTorch provide automatic differentiation (Gradients) and GPU acceleration — essential for deep learning.

🐍 TensorFlow / Keras: Build a Small NN for MNIST

✦ Step-by-step example

Using Keras Sequential API — simplest way to build neural networks.

import tensorflow as tf from tensorflow import keras from tensorflow.keras import layers # Load dataset (MNIST) (x_train, y_train), (x_test, y_test) = keras.datasets.mnist.load_data() x_train = x_train.reshape(-1, 784) / 255.0 x_test = x_test.reshape(-1, 784) / 255.0 # Build a small neural network model = keras.Sequential([ layers.Dense(128, activation='relu', input_shape=(784,)), layers.Dropout(0.2), # regularization layers.Dense(64, activation='relu'), layers.Dense(10, activation='softmax') ]) # Compile: optimizer, loss, metrics model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy']) # Train history = model.fit(x_train, y_train, batch_size=32, epochs=5, validation_split=0.1) # Evaluate test_loss, test_acc = model.evaluate(x_test, y_test) print(f"Test accuracy: {test_acc:.4f}")
🚀 Why Keras/TensorFlow: High-level, beginner-friendly, production-ready. Built-in datasets, callbacks, and deployment (TF Lite, TF Serving).
📈 Expected output: ~97% test accuracy after 5 epochs. The model learns digit recognition from raw pixels.

🔥 PyTorch: Build the Same NN from Scratch

✦ Step-by-step with nn.Module

PyTorch offers imperative style and dynamic computation graphs — great for research & debugging.

import torch import torch.nn as nn import torch.optim as optim from torch.utils.data import DataLoader, TensorDataset from torchvision import datasets, transforms # Load MNIST transform = transforms.Compose([transforms.ToTensor(), transforms.Lambda(lambda x: x.view(-1))]) train_dataset = datasets.MNIST('./data', train=True, download=True, transform=transform) test_dataset = datasets.MNIST('./data', train=False, transform=transform) train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True) test_loader = DataLoader(test_dataset, batch_size=32) # Define neural network class class SmallNN(nn.Module): def __init__(self): super().__init__() self.fc1 = nn.Linear(784, 128) self.relu = nn.ReLU() self.dropout = nn.Dropout(0.2) self.fc2 = nn.Linear(128, 64) self.fc3 = nn.Linear(64, 10) def forward(self, x): x = self.relu(self.fc1(x)) x = self.dropout(x) x = self.relu(self.fc2(x)) x = self.fc3(x) # no softmax here (CrossEntropyLoss includes it) return x model = SmallNN() criterion = nn.CrossEntropyLoss() optimizer = optim.Adam(model.parameters(), lr=0.001) # Training loop for epoch in range(5): model.train() for images, labels in train_loader: optimizer.zero_grad() outputs = model(images) loss = criterion(outputs, labels) loss.backward() optimizer.step() print(f"Epoch {epoch+1} completed") # Evaluation model.eval() correct = 0 total = 0 with torch.no_grad(): for images, labels in test_loader: outputs = model(images) _, predicted = torch.max(outputs, 1) total += labels.size(0) correct += (predicted == labels).sum().item() print(f"Test accuracy: {100 * correct / total:.2f}%")
🧠 Why PyTorch: More explicit control, Pythonic, dynamic graphs for variable-length inputs, used heavily in research (Transformers, LLMs).

🧠 Understanding Forward & Backward Pass

✦ How a small NN learns

Forward pass: Input data flows through layers, activations produce predictions. Backward pass (backprop): Gradients of loss w.r.t parameters computed via chain rule. Optimizer updates weights.

# Conceptual gradient descent in frameworks with tf.GradientTape() as tape: # TF predictions = model(inputs) loss = loss_fn(predictions, labels) gradients = tape.gradient(loss, model.trainable_variables) optimizer.apply_gradients(zip(gradients, model.trainable_variables))
📚 Learning rate effect: Small LR → slow convergence; large LR → overshoot. Adam adaptive LR is default choice.

📊 Key Hyperparameters & Tuning

⚙️ Building your small NN successfully
  • Number of layers/neurons: Start with 1-2 hidden layers, 64-128 neurons.
  • Batch size: 16, 32, 64 (memory/speed trade-off).
  • Epochs: Monitor validation loss; use early stopping.
  • Activation: ReLU for hidden, softmax/sigmoid for output.
  • Regularization: Dropout (0.2-0.5), L2 weight decay.
🎯 Where to tune: Grid search or random search, but first overfit a single batch to debug model.

🐞 Debugging & Improving Your Small NN

🔍 Common pitfalls
  • Loss not decreasing → learning rate too low/high, wrong loss function.
  • Overfitting (gap train/val) → add dropout, reduce layers, increase data.
  • Underfitting → increase model capacity, train longer.
✅ Best practices
  • Normalize input data (zero mean, unit variance).
  • Use validation split & early stopping callbacks.
  • Monitor gradients (clip if exploding).
# Early stopping callback in TF callback = tf.keras.callbacks.EarlyStopping(monitor='val_loss', patience=3) model.fit(..., callbacks=[callback])
