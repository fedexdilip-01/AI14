Day 7 — Model Generalization & Regularization Techniques

📉 Underfitting (High Bias)

✦ What is it?

Model is too simple to capture underlying patterns in data. Performs poorly on both training and test sets. "Model is too rigid."

🎯 Why does it happen? — Linear model on non-linear data, too few features, excessive regularization, or shallow architecture.
💡 Example: Using linear regression to predict housing prices when relationship is highly non-linear (size vs price saturates). Training error = 35%, test error = 38% → both high.
# Symptoms:
train_score = 0.62, test_score = 0.60
# Both low → underfitting. Solution: increase model complexity.

🔧 How to fix: Add more features, increase polynomial degree, use more powerful model (e.g., decision tree instead of linear), reduce regularization.

📈 Overfitting (High Variance)

✦ What is it?

Model learns training data too well, including noise and outliers. Generalizes poorly to unseen data. "Memorizes rather than learns."

🎯 Why does it happen? — Model too complex relative to data size, too many features, lack of regularization, or training for too many epochs.
💡 Example: Deep neural network with millions of parameters trained on only 500 images. Training accuracy = 100%, test accuracy = 55% → classic overfitting.
# Symptoms:
train_loss = 0.01, val_loss = 0.89
Large gap → overfitting. Solution: simplify architecture, add regularization.

🔧 How to fix: Regularization (L1/L2), reduce model complexity, early stopping, cross-validation, gather more data, data augmentation.

🛡️ Regularization: The Shield Against Overfitting

Regularization adds a penalty term to the loss function to discourage model complexity, forcing weights to stay small or sparse.

📌 L1 Regularization (Lasso)
Loss = Original Loss + λ * Σ|wᵢ|

Encourages sparsity — can shrink some weights exactly to zero → feature selection. Great for high-dimensional data.

📊 Example: In text classification, L1 eliminates irrelevant words (weights become zero).
📌 L2 Regularization (Ridge)
Loss = Original Loss + λ * Σ wᵢ²

Penalizes large weights but keeps all features. Distributes importance smoothly, prevents any single weight from dominating.

📈 Example: Linear regression with many correlated features → L2 stabilizes coefficient estimates.
💡 What about Elastic Net? Combines L1 + L2 (α * L1 + (1-α)*L2). Best of both worlds: sparsity + grouping effect.
# scikit-learn example
from sklearn.linear_model import Ridge, Lasso, ElasticNet
ridge = Ridge(alpha=1.0) # L2 penalty
lasso = Lasso(alpha=0.1) # L1 penalty
# alpha = λ (regularization strength — larger = more regularization)

⚖️ The Bias-Variance Tradeoff (Core Intuition)

Total Error = Bias² + Variance + Irreducible Error

🧠 Bias

Error from wrong assumptions. High bias → underfitting (simple model).

📊 Variance

Error from sensitivity to fluctuations. High variance → overfitting.

📍 Analogy: Throwing darts at a bullseye.
High bias → consistently off-target (systematic error).
High variance → scattered shots, inconsistent (random error).
Sweet spot: low bias + low variance → perfect generalization.
# Increasing model complexity ↑ decreases bias, increases variance.
# Regularization ↑ decreases variance but increases bias.

🏠 Real-World Case Study: House Price Prediction

Scenario: 2000 samples, 80 features (sqft, bedrooms, location, year built, etc.).

❌ Overfitting example

Using a high-degree polynomial regression or deep ensemble without regularization. Train R² = 0.99, Test R² = 0.62. Model memorized idiosyncrasies like “house sold on Tuesday” noise.

Fix: Ridge regression (L2) to shrink coefficients, or reduce polynomial features.
❌ Underfitting example

Using only one feature (sqft) with simple linear regression. Train R² = 0.45, Test R² = 0.43 → unable to capture location, condition impact.

Fix: Add meaningful features, try random forest or gradient boosting.
# Ridge regularization path
from sklearn.linear_model import RidgeCV
ridge = RidgeCV(alphas=[0.1, 1.0, 10.0], scoring='r2')
ridge.fit(X_train, y_train) # alpha selected by cross-validation
📌 Key takeaway: Regularization hyperparameter (λ/alpha) controls complexity. Cross-validation finds optimal tradeoff.

🧰 Advanced Regularization & Anti-Overfitting Tools

⏹️ Early Stopping

Stop training when validation error starts increasing. Prevents overfitting in neural networks & gradient boosting.

📉 Dropout (Neural Nets)

Randomly drop neurons during training → forces redundant representations, reduces co-adaptation.

📸 Data Augmentation

Generate synthetic training samples (rotate, flip images). Effectively increases dataset size, reduces overfitting.

🌳 Pruning (Decision Trees)

Remove branches that use little predictive power → simpler tree, better generalization.

# Early stopping with XGBoost
model = xgb.XGBClassifier(n_estimators=1000, early_stopping_rounds=10)
model.fit(X_train, y_train, eval_set=[(X_val, y_val)], verbose=False)

📌 Diagnostic & Action Guide (Learning Curves)

Learning curves (training vs validation error vs dataset size) reveal overfitting/underfitting.

✔ High bias (underfitting): Both curves converge at high error. → Add features, increase model capacity.
✔ High variance (overfitting): Large gap between curves. → Regularize, get more data, simplify.
✔ Just right: Validation error low, close to training error.
# Plot learning curves using sklearn
from sklearn.model_selection import learning_curve
train_sizes, train_scores, test_scores = learning_curve(model, X, y, cv=5)
🔁 Where to implement daily: Any supervised task — regression, classification, deep learning. Always monitor training vs validation metrics and apply regularization as needed.
