📌 What is AI Ethics & Why It Matters?

✦ The moral compass of ML

AI Ethics examines the societal impact of AI systems: fairness, accountability, transparency, privacy, and safety. It ensures technology benefits humanity without causing harm or discrimination.

🎯 Why crucial now? — AI systems influence hiring, loans, healthcare, criminal justice. Biased models amplify historical inequalities. Ethical AI is not optional — it's a necessity.
💡 Real scandal: Healthcare algorithm underpredicted risk for Black patients by 50% (2020). Hiring tools penalized women for resume gaps. Facial recognition had higher error rates for minorities.

⚖️ Types of Bias in ML

✦ Where bias creeps in
  • Historical Bias: Past societal biases reflected in training data.
  • Representation Bias: Certain groups underrepresented.
  • Measurement Bias: Features/labels measure differently across groups.
  • Algorithmic Bias: Model design choices exacerbate disparities.
# Example: Disparate impact in loan approval # Model approved 80% of majority group vs 40% of minority group # Ratio = 0.4/0.8 = 0.5 → violates fairness standards (<0.8 threshold)

📊 How to Detect & Measure Bias?

✦ Quantitative fairness metrics
  • Demographic Parity: Proportion of positive outcomes equal across groups.
  • Equalized Odds: Equal TPR and FPR across groups.
  • Disparate Impact: Ratio of positive outcome rates (should be >0.8).

Problem: Loan approval model using historical data rejected minority applicants at higher rate due to past redlining.

✅ Solutions applied
  • Removed protected attributes (race) but still proxy bias.

🔍 Explainable AI (XAI) — Why & How?

Why: Black-box models (deep learning) hide decision logic. Regulations (GDPR, EU AI Act) require 'right to explanation'.

SHAP (SHapley Additive Explanations)
import shap explainer = shap.Explainer(model, X_train) shap_values = explainer(X_test) shap.summary_plot(shap_values, X_test)
LIME (Local Interpretable Model-agnostic Explanations)

📝 Mini-Project Code Skeleton (Using Fairlearn + SHAP)

# pip install fairlearn shap pandas sklearn import pandas as pd from sklearn.model_selection import train_test_split from sklearn.ensemble import RandomForestClassifier from fairlearn.metrics import demographic_parity_difference from fairlearn.postprocessing import ThresholdOptimizer from shap import Explainer # Load dataset (e.g., UCI Adult Income) data = pd.read_csv("adult.csv") X = data.drop('income', axis=1) y = (data['income'] == '>50K').astype(int) sensitive = X['gender'] # privileged: Male, unprivileged: Female # Split X_train, X_test, y_train, y_test, sens_train, sens_test = train_test_split( X, y, sensitive, test_size=0.2, random_state=42 ) # Train base model model = RandomForestClassifier(n_estimators=50, random_state=42) model.fit(X_train, y_train) y_pred_base = model.predict(X_test) # Fairness metrics before mitigation dp_diff_base = demographic_parity_difference(y_test, y_pred_base, sensitive_features=sens_test) print(f"Demographic parity difference (base): {dp_diff_base:.3f}") # Apply post-processing mitigation mitigator = ThresholdOptimizer( estimator=model, constraints="demographic_parity", prefit=True ) mitigator.fit(X_train, y_train, sensitive_features=sens_train) y_pred_mitigated = mitigator.predict(X_test, sensitive_features=sens_test) dp_diff_mit = demographic_parity_difference(y_test, y_pred_mitigated, sensitive_features=sens_test) print(f"Demographic parity difference (mitigated): {dp_diff_mit:.3f}") # Explainability explainer = Explainer(model, X_train) shap_values = explainer(X_test) shap.summary_plot(shap_values, X_test, feature_names=X.columns)
📊 Expected output: Mitigated model shows lower demographic parity difference (closer to 0) while maintaining reasonable accuracy. SHAP reveals which features drive predictions.
