Day 5 — Logistic Regression · k-Nearest Neighbors (k-NN)

📉 Logistic Regression

✦ What is it?

Despite its name, logistic regression is a classification algorithm used to predict the probability of a binary (or multi-class) outcome. It applies the sigmoid function to map linear outputs to [0,1] probability space.

🎯 Why logistic regression? — Simple, fast, interpretable, gives well-calibrated probabilities. Works great when decision boundary is roughly linear.
💡 Classic example: Email spam detection
Features: word frequencies, sender info → Model outputs P(Spam). If P ≥ 0.5 → "Spam" else "Not Spam".
Decision boundary: linear in log-odds space.
from sklearn.linear_model import LogisticRegression
model = LogisticRegression()
model.fit(X_train, y_train)
proba = model.predict_proba(X_test)[:,1] # probability of class 1

📌 Where used? — Medical diagnosis (disease vs healthy), credit default prediction, churn modeling, ad click prediction.

👥 k-Nearest Neighbors (k-NN)

✦ What is it?

k-NN is a non-parametric, lazy learning algorithm that classifies a new point based on the majority vote (or average) of its k nearest neighbors in the feature space. Distance metrics: Euclidean, Manhattan, etc.

🎯 Why k-NN? — No training phase, intuitive, adapts to complex decision boundaries, works well with small datasets.
💡 Example: Handwritten digit recognition
Given an image of a digit (8x8 pixels), find k most similar images from training set. Majority label decides digit (0-9).
k=3 → neighbors: [5,5,6] → predicts 5.
from sklearn.neighbors import KNeighborsClassifier
knn = KNeighborsClassifier(n_neighbors=5)
knn.fit(X_train, y_train) # just stores data
predictions = knn.predict(X_test)

📌 Where used? — Recommendation systems, anomaly detection, image classification (small scale), medical pattern recognition.

⚙️ How They Work: Intuition & Mechanics

🧠 Logistic Regression — Decision Boundary

Logistic regression calculates log-odds = w·x + b and applies sigmoid: σ(z) = 1/(1+e⁻ᶻ). The model finds coefficients using maximum likelihood estimation (gradient descent). Output is a smooth probability curve.

Sigmoid(z) = 1 / (1 + exp(-z))
Log-odds = ln(P/(1-P)) = β₀ + β₁x₁ + ... + βₙxₙ
📏 k-NN — Distance-based Classification

For a new sample, compute distance to every stored training point. Select k closest, then apply majority voting (classification) or average (regression). Requires feature scaling (otherwise attributes with larger magnitude dominate).

Euclidean distance: d(p,q) = √ Σ (qᵢ - pᵢ)²
Decision boundary formed implicitly by Voronoi tessellation.
🔍 Key difference: Logistic Regression learns a parametric decision boundary (probabilistic) and is fast at inference. k-NN is memory-based, no training, but slower for large datasets & requires careful k selection.

📋 Logistic Regression: What/Why/How/Where

AspectDetails
WhatStatistical model for binary/multiclass classification that outputs probabilities using sigmoid/softmax.
WhyInterpretable coefficients (feature importance), probabilistic output, efficient training, less prone to overfitting with regularization.
HowOptimize log-loss (cross-entropy) via gradient descent / Newton methods. Regularization (L1/L2) can be added.
WhereBanking (loan default), healthcare (diabetes prediction), HR (employee attrition), NLP sentiment polarity.
🏥 Real‑world case: Predicting patient readmission risk within 30 days. Features: age, previous visits, medications. Logistic regression gives probability of readmission → trigger preventive care.

📋 k-NN: What/Why/How/Where

AspectDetails
WhatInstance-based, lazy learner; classifies based on majority class of k nearest neighbors.
WhySimple to implement, no assumptions about data distribution, naturally handles multi-class, nonlinear.
HowChoose k (hyperparameter), distance metric (Euclidean, Manhattan), store all training data. Inference = O(N).
WhereRecommender engines (user-based CF), gene expression classification, computer vision (small datasets), missing data imputation.
🎬 Movie recommendation: Find k users with most similar taste (ratings) → recommend movies the active user hasn’t seen but neighbors liked.

🔎 Complete Case Study: Credit Card Fraud Detection (Logistic Regression vs k-NN)

Problem: Identify fraudulent transactions from legitimate ones. Highly imbalanced dataset (fraud ≈ 0.1%).

📌 Logistic Regression approach
  • Features: transaction amount, time, merchant category, user location.
  • Outputs probability of fraud. Use threshold tuning (precision/recall).
  • Interpretability: coefficients show risky attributes (e.g., high amount + unusual location).
  • Scales well to millions of rows with SGD.
🔍 k-NN approach
  • Define similarity based on transaction features (scaled).
  • Classify new transaction by checking k nearest past transactions.
  • Works well if frauds appear in clusters.
  • Challenges: high-dimensional, need optimized distance + k selection.
# Logistic Regression for fraud (balanced class weight)
lr = LogisticRegression(class_weight='balanced', C=0.1)
lr.fit(X_train, y_train)
y_pred_proba = lr.predict_proba(X_test)[:,1]
# k-NN baseline
knn = KNeighborsClassifier(n_neighbors=5, weights='distance')
knn.fit(X_train_small, y_train_small)
🏆 Where both excel: Logistic regression is baseline production model (fast interpretable), k-NN useful for localized fraud patterns but memory heavy. Hybrid ensemble possible.

🧪 Intuitive Example: Tumor Malignancy Classification

Features: tumor size (mm) and patient age. Label: Malignant (1) or Benign (0). Compare the two classifiers.

📐 Logistic Regression outcome

Learns a linear decision boundary: P(Malignant) = sigmoid(0.08*size + 0.02*age - 4.5). For a given size/age, produces smooth probability. Works well when classes are linearly separable.

👥 k-NN outcome (k=5)

Draws irregular boundary based on actual tumor cases. For a new tumor, looks at 5 most similar tumors (closest in size/age space). If 3/5 are malignant → classify malignant. Good for complex local patterns.

💡 Pro tip: For medical applications, logistic regression provides confidence intervals and odds ratios (e.g., "each unit increase in size raises odds of malignancy by 12%"). k-NN might capture rare subtypes but is less explainable to doctors.

🌍 Where in the real world? Industry applications

🏦 Financial services: Logistic regression for credit scoring, fraud detection. k-NN for anomaly detection in transaction sequences.

🩺 Healthcare: Logistic regression predicts disease onset (diabetes, heart failure). k-NN used in medical image retrieval (find similar histology patches).

📱 E‑commerce: Logistic regression for click-through rate (CTR) estimation. k-NN for "customers who bought this also liked" (collaborative filtering).

🌾 Agriculture: Logistic regression to predict crop disease (healthy/infected). k-NN for soil type classification based on sensor readings.

✅ Best practice summary: Start with logistic regression as a baseline; if decision boundary is highly non-linear and dataset moderate size, try k-NN with cross-validated k. Always standardize features for k-NN. For probability outputs and feature importance, logistic regression wins.

🎯 Day 5 Core Takeaways:

✔ Logistic Regression = probabilistic linear classifier, great for interpretable baselines, outputs risk scores.
✔ k-NN = non-parametric lazy learner, captures local structures but requires distance metrics & scaling.
✔ Both are fundamental classification algorithms — understand their trade-offs: speed vs. flexibility, linear vs. non-linear, memory vs. parametric.
✔ Where to apply: fraud, medicine, recommendations, NLP sentiment. Start simple, then ensemble!
