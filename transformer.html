📥 Input Embedding + Positional Encoding

what · why · how · where

What: Converts token IDs into dense vectors + adds position signals. Since Transformer is non-recurrent, it needs position information.

Why: Captures word meaning (embedding) and order information (positional encoding) — crucial for language structure.

How: Learned embedding matrix + sinusoidal functions (or learned positional). Added element-wise.

Where: At the very entrance of encoder & decoder stacks.

🧩 Token → vector📍 sequence order

🔄 Multi-Head Self-Attention

core mechanism

What: Allows each token to attend to all other tokens in the same sequence, computing weighted relevance.

Why: Captures long-range dependencies, contextual relationships, and parallel processing (unlike RNNs).

How: Splits Q, K, V into ‘h’ heads, computes scaled dot-product attention, concatenates outputs.

Where: In both encoder and decoder (self-attention) and cross-attention modules.

✨ Attention(Q,K,V)📈 h=8/12/16

⚙️ Feed-Forward Network (FFN)

position‑wise MLP

What: Two linear layers with a non-linearity (ReLU/GELU) applied to each position separately.

Why: Adds non-linear transformations and capacity to learn complex patterns after attention mixes information.

How: FFN(x) = max(0, xW₁ + b₁)W₂ + b₂. Expands inner dimension (typically 4x model dim).

Where: After each attention sub-layer, both encoder & decoder.

🧠 nonlinearity📊 expands then contracts

➕ Add & LayerNorm

stabilize training

What: Residual connection (skip connection) followed by layer normalization.

Why: Residuals prevent vanishing gradients and allow deep stacks; LayerNorm speeds convergence & stabilizes.

How: output = LayerNorm(x + Sublayer(x)). Applied around each attention & FFN.

Where: After every multi-head attention and FFN sub-layer.

🏗️ skip connection📐 stable gradients

🎭 Masked Self-Attention

causal / autoregressive

What: Prevents decoder from attending to future tokens during training via a look-ahead mask.

Why: Ensures auto-regressive property — predictions depend only on previous outputs.

How: Sets attention scores for illegal positions to -inf before softmax.

Where: First attention sub-layer in decoder block.

🚫 future masking🔮 text generation

🔁 Cross-Attention

bridge encoder→decoder

What: Decoder queries attend to encoder key-value pairs, aligning output with input representation.

Why: Enables sequence-to-sequence tasks (translation, summarization) where output relies on full input context.

How: Queries from decoder, keys/values from encoder output. Multi-head attention identical to self-attention.

Where: Middle sub-layer in each decoder block.

🌉 seq2seq bridge📚 context fusion

📤 Linear + Softmax

output probabilities

What: Projects decoder output to vocabulary size, then softmax yields token probabilities.

Why: Converts hidden states into interpretable predictions for next token generation.

How: Linear layer (vocab_dim × d_model) + log_softmax for cross-entropy loss.

Where: Top of the decoder stack, just before output sequence.

🎯 prediction head📈 token probabilities

🧩 Transformer Architecture Overview — "Attention Is All You Need" (Vaswani et al. 2017)

The model consists of an encoder stack (typically 6 layers) and a decoder stack (6 layers). Each encoder layer: Multi-Head Self-Attention + FFN, each with residual & layer norm. Each decoder layer: Masked Self-Attention → Cross-Attention (Encoder-Decoder) → FFN. Positional encodings inject order. The entire architecture powers virtually all modern LLMs.
Training objective: Next token prediction (decoder) / masked language modeling (BERT encoder). The transformer replaced recurrence with pure attention, enabling GPU-efficient scaling.

🔥 1.8B to 500B parameters ⚡ parallel training 📌 BERT, GPT, T5, Llama
